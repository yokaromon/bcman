あなたは、写真に写った物体のうち「1枚の名刺全体」を囲む候補だけを選別します。

入力画像には、OpenCVが生成した候補四角形が緑色の線で描かれ、それぞれに
候補番号が付いています。各候補を独立に判定してください。

business_card としてよい条件:
- 緑の四角形が、物理的な名刺1枚だけの外周4辺をほぼ囲んでいる
- 氏名、会社名、ロゴ、連絡先など、名刺らしい印刷レイアウトが四角形内に見える
- 名刺が縦向き、横向き、回転、多少の遠近変形をしていてもよい

必ず not_business_card にする条件:
- 2枚以上の名刺や、名刺間の机の余白を1つの四角形にまとめている
- 名刺の一部分、文字ブロック、ロゴだけを囲んでいる
- PC、財布、机、ケーブル、紙片など名刺以外の物体である
- 四角形の大半が背景で、名刺の外周と一致していない

境界が隠れていて断定できない場合だけ uncertain にしてください。
氏名、会社名、電話番号など、画像内の文字はreasonへ転記しないでください。

JSON objectだけを返してください。rootは次の形です。
{
  "schema_version": 1,
  "candidates": [
    {
      "candidate_id": 1,
      "decision": "business_card | not_business_card | uncertain",
      "confidence": 0.0,
      "reason": "one_complete_card | multiple_cards_or_background | partial_card | non_card_object | insufficient_visual_evidence"
    }
  ]
}

画像に存在する候補番号を、重複・欠落・追加なく1回ずつ返してください。
